# Клуб корпоративных бальных танцев — учёт занятий

Приложение для учёта занятий тренеров и учеников, абонементов, отработанных часов, актов и договоров.
Работает в браузере на Windows, Android и iPhone, а также как приложение для Android (APK).
Все данные хранятся в одной Google Таблице на Google Диске администратора. Сервер не нужен.

## Что умеет

| Роль | Возможности |
|---|---|
| **Администратор** | Всё, включая пользователей, настройки и нумерацию договоров |
| **Менеджер** | Ученики, тренеры, абонементы, расписание, группы, отчёты, акты, договоры, аренда, партнёры |
| **Тренер** | Свои ученики с остатком часов, отметка занятий, расписание для записи, группы и мероприятия, свои часы, чат «Тренерская» |
| **Ученик** | Свои абонементы и остаток часов, история занятий, запись на занятия, объявления |

- **Карточка ученика**: абонементы с полосой остатка (жёлтая, когда часы заканчиваются, красная, когда закончились), часы по каждому тренеру, история занятий.
- **Карточка тренера**: ученики (кто с кем и сколько часов), группы и мероприятия, индивидуальные занятия за выбранный период.
- **Сводная по тренерам**: часы (индивидуальные, групповые, мероприятия), сумма по ставкам и кнопка «Акт». Тренерам не видна.
- **Акты** формируются в Google Документах и PDF в папке «Акты — Клуб корпоративных бальных танцев» рядом с таблицей.
- **Сквозная нумерация договоров**: отдельные счётчики для учеников (У-0001), тренеров (Т-0001), партнёров (П-0001), аренды (А-0001) и прочих.
- **Отчёт «Тренер × ученик»** и конструктор отчётов: строки и столбцы на выбор (тренер, ученик, компания, тип, месяц, неделя, день недели), выгрузка в CSV для Excel.
- **Аренда** и **абонементы партнёров** ведутся отдельно.
- **Запись**: тренер открывает слоты, ученики записываются, после занятия тренер нажимает «Отметить», и часы списываются.
- **Чат** «Тренерская» и **объявления** для учеников.

## Установка (около 15 минут, один раз)

### 1. Таблица и код
1. Войдите в Google-аккаунт клуба. Он станет владельцем базы.
2. Создайте новую Google Таблицу (sheets.new) и назовите её, например, «Клуб танцев — база».
3. В таблице откройте меню **Расширения → Apps Script**.
4. В редакторе откройте файл `Код.gs` (`Code.gs`), удалите всё и вставьте содержимое [`apps-script/Code.gs`](apps-script/Code.gs).
5. Нажмите **＋ → HTML**, назовите файл ровно `Index` и вставьте содержимое [`apps-script/Index.html`](apps-script/Index.html).
6. Нажмите 💾 «Сохранить».

### 2. Первый запуск
1. Вверху выберите функцию `setup` и нажмите **Выполнить**.
2. Google попросит разрешения. Нажмите «Проверить разрешения», выберите аккаунт, затем «Дополнительно» → «Перейти к проекту» → «Разрешить». Это ваш собственный скрипт, поэтому предупреждение нормальное.
3. В журнале выполнения появится строка `Логин: admin  Пароль: …`. Тот же пароль записан в таблице на листе **Настройки**. При первом входе приложение попросит его сменить.

### 3. Публикация веб-приложения
1. Нажмите **Развернуть → Новое развертывание** → ⚙ → **Веб-приложение**.
2. Укажите:
   - **Выполнять как:** «От моего имени».
   - **У кого есть доступ:** «Все».
3. Нажмите **Развернуть** и скопируйте адрес вида `https://script.google.com/macros/s/…/exec`.

Этот адрес и есть приложение: откройте его в браузере на компьютере или телефоне. Пользователи входят по логинам, которые вы создадите в разделе **Пользователи**. Доступа к самой таблице у них нет: приложение работает от имени владельца и показывает каждому только разрешённое.

> На iPhone и Android в браузере можно добавить ярлык на главный экран: «Поделиться» → «На экран Домой».

### 4. Приложение для Android (APK)
1. В репозитории GitHub откройте **Settings → Secrets and variables → Actions → Variables → New repository variable**.
   Имя: `APP_URL`, значение: адрес из шага 3.
2. Откройте вкладку **Actions → «Сборка APK» → Run workflow**. Адрес можно вставить прямо в поле запуска.
3. Через 3–5 минут готовый файл появится в разделе **Releases** репозитория (`DanceClub-N.apk`). Скачайте его на телефон и установите, разрешив установку из этого источника.

Если собрать APK без адреса, приложение спросит его при первом запуске. Сменить адрес можно на экране «Нет связи».

APK подписывается ключом `android/app/club.keystore`, поэтому новые сборки ставятся поверх старых. Для собственного ключа добавьте секреты `KEYSTORE_BASE64`, `KEYSTORE_PASSWORD`, `KEY_ALIAS`, `KEY_PASSWORD`.

## Обновление приложения
После изменения кода в Apps Script откройте **Развернуть → Управление развертываниями → ✏ → Версия: Новая версия → Развернуть**. Адрес не меняется, APK пересобирать не нужно.

## Важно про таблицу
- Лучше вносить данные через приложение. Таблицу удобно использовать для просмотра и выгрузки (Файл → Скачать → Microsoft Excel или кнопка в «Настройках» приложения).
- Не переименовывайте листы и заголовки столбцов. Порядок столбцов менять можно, новые столбцы добавлять тоже.
- Листы «Пользователи» и «Сессии» содержат служебные данные входа. Не открывайте к ним доступ посторонним.
- Забыли пароль администратора? Запустите в редакторе функцию `resetAdminPassword`, и новый пароль появится в журнале.

## Ограничения
- Сохранение занимает несколько секунд: так работает Google Apps Script. Данные читаются одним запросом через сервис «Google Sheets API» (в редакторе: Сервисы → + → Google Sheets API); без него всё работает, но медленнее.
- Тестовые записи (ФИО начинается с «ТЕСТ») удаляет функция `removeTestData` в редакторе.
- Если аккаунт владельца обычный (gmail.com), Google показывает сверху полосу «Приложение создано пользователем Google Apps Script». Убрать её можно только с аккаунтом Google Workspace.
