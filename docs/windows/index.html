Клуб танцев для Windows

Приложение клуба отдельным окном, с ярлыком на рабочем столе. Windows 10 и 11.
⬇ Скачать установщикDanceClub-Setup.exe · 1,3 МБ · права администратора не нужны Переносная версияDanceClub-Portable.exe · без установки

Если с corpdance.ru не скачивается — запасная ссылка (GitHub).

Зачем, если есть сайт? Приложение открывает клуб напрямую с серверов Google — не зависит от настроек браузера, расширений и блокировок, из‑за которых на некоторых компьютерах сайт corpdance.ru не открывается или пишет «Не защищено». Вход, данные и обновления — те же, что на сайте и в телефоне.

Как установить

  1. Скачайте DanceClub-Setup.exe и откройте его.
  2. Если Windows покажет синее окно «Система Windows защитила ваш компьютер» — нажмите Подробнее → Выполнить в любом случае. Так Windows реагирует на любую новую программу без платной цифровой подписи; программа безопасна и не собирает данные.
  3. Если браузер пишет, что файл «обычно не скачивают» — откройте список загрузок, нажмите «…» → Сохранить (в Edge: «Сохранить» → «Всё равно сохранить»).
  4. Программа работает на встроенном в Windows движке Edge (WebView2). В Windows 11 он уже есть; на старой Windows 10 установщик сам докачает его (~2 МБ).
  5. Через несколько секунд появится ярлык «Клуб танцев» на рабочем столе и в меню «Пуск». Войдите своим логином и паролем — как на сайте.

Если не получается

  1. Защитник Windows удалил файл — откройте «Безопасность Windows» → «Защита от вирусов и угроз» → «Журнал защиты», выберите DanceClub и нажмите «Действия» → «Разрешить».
  2. «Нет связи с приложением клуба» — проверьте интернет и время на компьютере (неверная дата ломает защищённые соединения). На рабочем компьютере с корпоративным прокси или антивирусом с проверкой HTTPS попросите администратора разрешить script.google.com и *.googleusercontent.com.
  3. Можно открыть приложение и в любом браузере по прямой ссылке: открыть напрямую.

Обновлять программу не нужно: всё новое в приложении клуба появляется само. ← corpdance.ru
